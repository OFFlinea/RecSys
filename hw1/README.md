# Домашнее задание 1. Рекомендательные системы

**Студент:** Кузнецов Иван Александрович.

**Датасет:** [Amazon Reviews 2023](https://amazon-reviews-2023.github.io/),
Clothing, Shoes and Jewelry, [официальная 5-core выборка](https://amazon-reviews-2023.github.io/data_processing/5core.html).
Метаданные товаров — из [того же датасета Amazon Reviews 2023](https://huggingface.co/datasets/McAuley-Lab/Amazon-Reviews-2023#for-item-metadata).

Сравниваются пять собственных реализаций: ItemKNN, iALS, EASE, FM с метапризнаками
и timeSVD++. После очистки используются 302 019 взаимодействий,
37 289 пользователей и 5000 товаров. Основная метрика — NDCG@10,
дополнительная — Recall@10. Подбор выполняется на validation.

## Файлы

- `experiments.ipynb` — выполненный ноутбук: загрузка, EDA, протокол, модели, подбор, результаты и выводы.
- `models/` — отдельный файл для каждой модели.
- `requirements.txt` — зависимости.
- `.gitignore` — исключения для данных, окружений и кешей.

## Запуск

Нужен Python 3.11–3.13; работа выполнена на Python 3.13.0 и CPU.
Команды выполняются из корня проекта:

```bash
python -m venv .venv
```

Активация окружения: `.venv\Scripts\Activate.ps1` в PowerShell
или `source .venv/bin/activate` в Linux/macOS. Затем:

```bash
python -m pip install -r requirements.txt
jupyter lab experiments.ipynb
```

В Jupyter выбрать **Restart Kernel and Run All Cells**. Запуск без интерфейса:

```bash
jupyter nbconvert --to notebook --execute --inplace --ExecutePreprocessor.timeout=-1 experiments.ipynb
```

Ноутбук сам скачивает взаимодействия и карточки товаров. Файл взаимодействий
занимает около 400 МБ. Для поиска всех карточек может потребоваться прочитать
до 18 ГБ справочника по сети; сохраняются только нужные записи.
Загрузка метаданных продолжается с контрольной точки после обрыва.
После загрузки используются локальные файлы. Для подготовки нужно несколько ГБ RAM.
Данные не включаются в репозиторий. Случайное зерно и параметры зафиксированы в коде.

Загрузка, подготовка данных, признаки и оценка находятся в основном ноутбуке.
Реализации пяти моделей находятся в отдельных файлах `models/`.
Все результаты и выбранные настройки приведены в выполненных ячейках ноутбука.
Ограничения исходного 5-core и исторической доступности метаданных описаны в отчёте.
